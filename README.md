# 驚愕のライフサイクル表を知る

40代・50代を中心とした家庭向けに、質問へ答えるだけで今後30年間の支出を見える化する、スマートフォン優先の静的Webアプリです。

## 主な機能

- 年齢、家族構成、教育方針、住宅費、車、旅行、外食、嗜好品、習い事をボタンで入力
- 20歳から75歳以上まで、5歳刻みの押しやすい年齢選択
- 5年ごとの支出グラフ、30年間の総額、支出ピーク、カテゴリ別内訳を表示
- 生活の一部を見直した場合の節約額を、その場で比較
- 入力内容は外部へ送信せず、ブラウザ内だけで計算
- 画面の端をときどき歩く、軽量なトイプードルのSVGアニメーション

## ローカルで確認する

追加のパッケージは不要です。リポジトリのルートで次を実行します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

## GitHub Pagesで公開する

1. このリポジトリをGitHubへpushします。
2. GitHub上で **Settings** → **Pages** を開きます。
3. **Build and deployment** の **Source** で「Deploy from a branch」を選択します。
4. 公開するブランチ（例: `main`）とフォルダ「`/ (root)`」を選び、**Save** を押します。
5. 数分後に表示される公開URLへアクセスします。

`index.html`、`style.css`、`script.js` だけの静的構成のため、ビルド作業は不要です。

## 支出計算について

表示額は一般的な費用をもとにした概算です。将来の物価変動、税金、医療費、日常生活費などは含みません。実際の資金計画を保証するものではありません。
